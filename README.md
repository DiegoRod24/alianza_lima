# Rincón del Hincha Grone

Tienda/experiencia digital independiente para polos, telas, banderolas y pedidos personalizados de hinchas blanquiazules.

## Estado
Primera versión responsive: portada inmersiva, historia/identidad, catálogo, personalización, reserva y carrito local.

> Proyecto independiente, no oficial. Antes de una venta comercial pública conviene revisar permisos de uso de marcas, escudos y material audiovisual.
